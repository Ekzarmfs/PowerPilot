Documentation & FAQ

Technical answers, security guarantees, and telemetry mechanisms

How does PowerPilot differ from the default Windows 11 Battery Saver?
Windows 11 Battery Saver only triggers at low thresholds (e.g. 20%), dims screen brightness, and halts background push notifications. PowerPilot is an active energy governor: it monitors individual process power draw via Windows low-level counters, switches Windows Power Scheme GUIDs dynamically, identifies background memory hogs, and enables 1-click Clean Sweeps before battery drops to critical levels.
Is the Clean Sweep action safe? Could it crash my laptop?
Yes, Clean Sweep is 100% safe. PowerPilot implements a strict blacklist and whitelist filter. Core system services (e.g., explorer.exe, dwm.exe, svchost.exe, csrss.exe, lsass.exe) are strictly protected and cannot be terminated. Clean Sweep targets only user-space desktop applications.
How does PowerPilot switch Windows Power Schemes?
PowerPilot utilizes Windows Native Powrprof.dll APIs and executes PowerSetActiveScheme via Win32 P/Invoke in PowerPilotNative.cs and powercfg /setactive fallback. This changes the CPU frequency governor, thermal policy, and core unparking profile at the OS kernel level without needing third-party drivers.
What is the technical stack of PowerPilot?
PowerPilot is engineered with Python 3.11+ and CustomTkinter for a hardware-accelerated Windows 11 Fluent dark UI, psutil for cross-process metrics, and a compiled C# Win32 Native binary (PowerPilotNative.exe) for zero-latency kernel power calls.

System Architecture & Code Deep Dive

Detailed engineering breakdown of PowerPilot's components and Windows kernel bindings

1. Frontend UI Engine (`customtkinter`)

Designed around the Windows 11 Fluent 2 elevation hierarchy:

  • Obsidian Base (`#090d16`): Deep horizon background to minimize OLED display power draw.
  • Milled Titanium Cards (`#141a29`): Standard surface elevation with crisp 1px borders.
  • Electric Ion Accent (`#38bdf8`): High-clarity status cues evoking electrical ionization.
  • Non-Blocking Updates: Smooth 33 FPS animations driven by Tkinter event loops with zero CPU lockup.

2. Process Energy Tracker (`core/process_tracker.py`)

Continuously tracks and computes process impact metrics:

  • Relative Drain Metric: Evaluates CPU percentage and memory footprint to rank apps into Critical, High, Moderate, or Low drain categories.
  • Protected Whitelist: System daemons like explorer.exe and svchost.exe are immune to bulk kill operations.
  • Multi-Process Aggregation: Automatically aggregates multi-instance browsers (e.g. Chrome's 14 tabs) into a single actionable row.

3. Native Windows Interop (`core/PowerPilotNative.cs`)

Compiled C# helper bridging Python to Win32 kernel power APIs:
